# 产品架构文档

## 产品的核心模块

MathOdyssey 由以下核心模块组成，每个模块有明确的职责和边界。

```
┌─────────────────────────────────────────────────────┐
│                    首页 / 导航                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐  │
│  │ 时间轴    │  │ 概念图谱  │  │  学习路径        │  │
│  │ 系统      │  │ 系统      │  │  系统            │  │
│  └────┬─────┘  └────┬─────┘  └────────┬─────────┘  │
│       │              │                 │            │
│       ▼              ▼                 ▼            │
│  ┌─────────────────────────────────────────────┐    │
│  │              节点详情页                       │    │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  │    │
│  │  │ 内容卡片  │  │ 互动实验  │  │ 挑战问题  │  │    │
│  │  │ 系统      │  │ 系统      │  │ 系统      │  │    │
│  │  └──────────┘  └──────────┘  └──────────┘  │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
└─────────────────────────────────────────────────────┘
```

| 模块 | 职责 | MVP 范围 |
|------|------|----------|
| 时间轴系统 | 历史时间轴的展示和交互 | 水平时间轴、缩放、平移、节点点击 |
| 概念图谱系统 | 数学概念关系的可视化 | MVP 不含，Phase 2 实现 |
| 互动实验系统 | 数学实验的交互界面 | 4 类基础实验 |
| 内容卡片系统 | 历史和数学内容的展示 | 基础卡片布局 |
| 学习路径系统 | 预设和自定义学习路径 | MVP 不含，Phase 4 实现 |
| 题目与挑战系统 | 验证理解的问题集 | 基础挑战问题 |

## 用户主要路径

```
进入首页
    │
    ▼
浏览时间轴 ──────────────────────────────────┐
    │                                        │
    ▼                                        ▼
点击感兴趣的时代节点                    搜索/筛选节点
    │                                        │
    ▼                                        ▼
查看节点详情 ─────────────────────────────────┘
    │
    ├──────────────────┬──────────────────┐
    ▼                  ▼                  ▼
阅读历史背景      参与互动实验        尝试挑战问题
    │                  │                  │
    ▼                  ▼                  ▼
理解数学概念      动手探索发现        验证理解程度
    │                  │                  │
    └──────────────────┴──────────────────┘
                       │
                       ▼
              继续探索下一个节点
                       │
                       ▼
              查看概念之间的关联
```

### 关键路径说明

**路径 1：时间轴探索（主要路径）**
用户沿时间轴浏览，被某个时代或问题吸引，点击进入节点详情，参与互动实验，理解概念后继续探索。

**路径 2：主题探索（次要路径）**
用户对某个数学主题（如"几何"或"代数"）感兴趣，通过筛选找到相关节点，按主题学习。

**路径 3：深度学习（延伸路径）**
用户在某个节点深入探索，完成所有挑战问题，查看相关概念，理解概念之间的联系。

## 时间轴系统

### 功能概述

时间轴是平台的主入口，以水平方向展示数学史的时间脉络。用户可以浏览、缩放、平移，点击节点进入详情。

### MVP 功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 水平滚动 | 鼠标拖拽或触摸滑动浏览时间轴 | P0 |
| 缩放控制 | 滚轮缩放或按钮缩放，调整时间跨度 | P0 |
| 节点展示 | 在时间轴上显示节点标记和标题 | P0 |
| 节点点击 | 点击节点跳转到详情页 | P0 |
| 时代标记 | 标注不同历史时代（古埃及、古希腊等） | P1 |
| 当前位置指示 | 显示当前视口对应的大致年代 | P2 |

### 后续功能

| 功能 | 描述 | 计划阶段 |
|------|------|----------|
| 地理视图 | 在地图上展示数学发展的地理分布 | Phase 3 |
| 并行时间线 | 展示不同文明的并行发展 | Phase 3 |
| 节点筛选 | 按时代、概念类型、难度筛选 | Phase 3 |
| 搜索 | 按关键词搜索节点 | Phase 4 |

### 交互设计要点

- 时间轴应有明确的起点（约公元前 3000 年）和终点（现代）
- 节点间距应反映实际时间跨度，但为可读性做适当调整
- 缩放级别不同，展示的信息密度不同（远看只显示时代，近看显示具体节点）
- 移动端适配为垂直时间轴或水平滑动

## 概念图谱系统

### 功能概述

概念图谱是时间轴的补充视图，以网络图形式展示数学概念之间的关系。节点代表概念，边代表概念之间的关系（前置、包含、演进等）。

### 设计方向

- 节点大小反映概念的重要程度
- 节点颜色反映所属时代
- 边的类型区分不同关系（前置知识、演进、应用）
- 支持缩放和拖拽
- 点击节点可跳转到对应的详情页

### 计划阶段

Phase 2 实现基础图谱，Phase 4 完善交互和数据。

## 互动实验系统

### 功能概述

互动实验是平台的核心价值所在。每个实验让用户通过操作来发现数学概念，而不是被动阅读。

### 实验分类

| 类型 | 描述 | 示例 | MVP 覆盖 |
|------|------|------|----------|
| 几何实验 | 拖拽点、线、面，观察几何关系 | 毕达哥拉斯面积验证 | 是 |
| 代数实验 | 调整参数，观察代数关系变化 | 二次方程面积完成法 | 是 |
| 概率实验 | 进行随机实验，观察统计规律 | 掷骰子大数定律 | 是 |
| 微积分实验 | 操作极限过程，理解变化率 | 切线斜率追踪器 | 是 |
| 数论实验 | 探索数的性质和规律 | 进制转换器 | 否（Phase 2） |
| 图论实验 | 在图上进行路径探索 | 七桥问题 | 否（Phase 2） |

### 实验通用流程

```
场景介绍 → 自由探索 → 发现规律 → 公式/概念提炼
   │           │           │           │
   ▼           ▼           ▼           ▼
历史问题    拖拽/调整    观察变化    理解数学
引入情境    参数/形状    提示发现    概念本质
```

### 技术要求

- 每个实验是独立的 React 组件
- 通过 props 接收配置数据
- 支持响应式布局
- 无内容依赖（实验组件不包含历史叙述）

## 内容卡片系统

### 功能概述

内容卡片用于展示节点的各类信息，包括历史背景、数学概念、学习目标、挑战问题等。

### 卡片类型

| 类型 | 用途 | 内容 |
|------|------|------|
| 节点摘要卡 | 时间轴上的节点预览 | 缩略图、标题、时代、关键概念 |
| 历史叙述卡 | 展示历史背景 | 时代、地点、人物、问题描述 |
| 概念解释卡 | 展示数学概念 | 概念名称、定义、公式、图示 |
| 学习目标卡 | 展示学习目标 | 目标列表、难度标记 |
| 挑战问题卡 | 展示练习题 | 题目、选项/输入、提示、答案 |
| 实验入口卡 | 引导进入互动实验 | 实验名称、描述、预览图 |

### 设计原则

- 卡片可折叠/展开
- 信息层级清晰（标题 → 摘要 → 详情）
- 支持多媒体嵌入（图片、SVG、公式）
- 响应式布局（桌面多列，移动端单列）

## 学习路径系统

### 功能概述

学习路径是预设的节点序列，引导用户按特定主题或难度进行学习。

### 路径类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 主题路径 | 围绕特定数学主题 | "几何的诞生"：丈量土地 → 毕达哥拉斯 → 欧几里得 → 坐标系 |
| 时代路径 | 按历史时代顺序 | "古希腊数学"：毕达哥拉斯 → 欧几里得 → 阿基米德 |
| 难度路径 | 按难度递进 | "从直观到抽象"：丈量土地 → 面积公式 → 极限 → 积分 |
| 自定义路径 | 用户自己选择节点序列 | 用户创建的个人学习路径 |

### 计划阶段

Phase 4 实现预设路径和路径推荐。

## 题目与挑战系统

### 功能概述

每个节点附带挑战问题，用于验证用户对数学概念的理解。

### 题目类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 历史重现 | 用历史方法解决问题 | "用古埃及方法计算这块三角形土地的面积" |
| 概念应用 | 将概念应用到新情境 | "用毕达哥拉斯定理计算这个三角形的斜边" |
| 探索发现 | 通过操作发现规律 | "调整正多边形的边数，你发现了什么规律？" |
| 跨时代连接 | 连接不同时代的概念 | "阿基米德的穷竭法和现代积分有什么关系？" |

### MVP 范围

每个节点 2-3 道挑战问题，以"概念应用"和"历史重现"为主。

### 后续功能

- 自动评分
- 提示系统
- 解析和反馈
- 难度自适应
