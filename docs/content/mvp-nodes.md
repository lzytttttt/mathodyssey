# MVP 数学史节点规划

本文档规划第一版（MVP）的 12 个数学史节点。选择标准：视觉化潜力强、学习价值高、实现难度适中、覆盖时代广泛。

---

## 节点 01：古埃及丈量土地

| 字段 | 内容 |
|------|------|
| id | `egypt-land-measurement` |
| 标题 | 尼罗河畔的土地丈量 |
| 所属时代 | ancient-egypt |
| 大致年代 | 约公元前 2000 年 |
| 历史问题 | 尼罗河每年泛滥后，土地边界被冲毁，如何重新划分土地并计算税收？ |
| 数学概念 | 矩形面积、三角形面积、比例、相似三角形 |
| 对应学习阶段 | K12 小学高年级 ~ 初中 |
| 互动实验形式 | SVG 拖拽丈量：用户在不规则地块上拖拽测量绳，将其分割为矩形和三角形，计算总面积 |
| 现代连接 | 土地测量、建筑规划、几何计算 |
| 为什么适合 MVP | 视觉化极强（地块分割）、历史背景清晰、概念直观、难度适中 |
| 后续扩展方向 | 埃及分数系统、金字塔几何、莱因德纸草书问题集 |

## MVP 节点选择总结

### 时代覆盖

| 时代 | 节点数 | 节点 |
|------|--------|------|
| 古埃及 | 1 | 丈量土地 |
| 古巴比伦 | 1 | 六十进制 |
| 古希腊 | 3 | 毕达哥拉斯、欧几里得、阿基米德 |
| 古中国 | 1 | 鸡兔同笼 |
| 古印度 | 1 | 零与负数 |
| 伊斯兰黄金时代 | 1 | 代数 |
| 近代早期 | 3 | 坐标系、微积分、概率论 |
| 18 世纪 | 1 | 图论 |

### 难度分布

| 难度 | 节点数 | 节点 |
|------|--------|------|
| L1 (入门) | 1 | 六十进制 |
| L2 (基础) | 4 | 丈量土地、毕达哥拉斯、鸡兔同笼、零与负数 |
| L3 (中等) | 4 | 欧几里得、代数、坐标系、概率论 |
| L4 (进阶) | 2 | 阿基米德、图论 |
| L5 (挑战) | 1 | 微积分 |

### 互动实验类型分布

| 实验类型 | 节点数 | 节点 |
|----------|--------|------|
| SVG 拖拽 | 5 | 丈量土地、毕达哥拉斯、代数、坐标系、微积分 |
| 滑块/控件 | 3 | 六十进制、阿基米德、鸡兔同笼 |
| 数轴操作 | 1 | 零与负数 |
| 模拟器 | 1 | 概率论 |
| 路径探索 | 1 | 七桥问题 |
| 公理构建 | 1 | 欧几里得 |

### 选择理由

1. **视觉化潜力强**：每个节点都有明确的视觉化方向（拖拽、动画、图表）
2. **学习价值高**：覆盖数学核心概念（几何、代数、极限、概率、图论）
3. **实现难度适中**：MVP 阶段可用 SVG + 简单交互实现
4. **时代覆盖广**：从公元前 2000 年到 18 世纪，展示数学发展的完整脉络
5. **文化多样性**：涵盖埃及、巴比伦、希腊、中国、印度、伊斯兰、欧洲数学
6. **概念递进**：从直观的面积计算到抽象的极限和概率，难度逐步提升
